03 🎯 LEARN

Selecting Features: WHAT vs WHERE

Select by Attribute

Uses descriptive information in a table.

Example: Type = Academic
Think: WHAT?

Select by Location

Uses spatial relationships.

Example: Buildings inside campus
Think: WHERE?
QuestionReasoning
Bus stops with sheltersAttribute / WHAT
Hospitals inside District ALocation / WHERE
Primary roadsAttribute / WHAT
Schools near a main roadSpatial / WHERE
Selection identifies matching features. It does not automatically prove that your data or condition are correct.
04 📏 EXPLORE

Buffer: How Near Is Near?

Near is subjective. GIS needs a measurable condition.

FEATURE+DISTANCE→BUFFER ZONE
📍 Point
Hospital, school, bus stop
〰️ Line
Road, river, railway
⬡ Polygon
Lake, protected area
Limitation: A 300 m straight-line buffer does not necessarily mean a 300 m walking route.
📘 READING 02

05 ✂️ LEARN

Clip, Intersect & Dissolve

✂️ CLIP

CUT / EXTRACT

Keep only what falls inside a boundary.

🔀 INTERSECT

OVERLAP / COMBINE

Identify shared geographic overlap.

🧩 DISSOLVE

MERGE SIMILAR

Combine features sharing a common attribute.

Roads from the whole city, but only roads inside campus?

Clip.

Buildings overlapping flood-risk areas?

Intersect or an appropriate spatial relationship analysis.

Selection identifies matching features in an existing dataset. Clip and Intersect can create new output datasets.

📘 READING 03

Choosing the Right Vector Analysis

A GIS analyst does not begin with “I want to use Buffer.” Start with the geographic question.

ASK→IDENTIFY→RELATE→ANALYSE→INTERPRET
GIS analysis is not memorising tools. Choose appropriate operations to answer a geographic question and interpret the result carefully.

Week 07 Wrap-Up

Think Before You Click

You have moved from organising GIS data to using geographic relationships to answer questions. The important skill is not memorising where tools are located. It is recognising the problem, identifying the relationship, choosing an appropriate analysis and interpreting the result responsibly.

A GIS analyst asks the right question before choosing the tool.
